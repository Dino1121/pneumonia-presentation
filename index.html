2. 프로젝트 목적 및 동기

프로젝트 목적

Chest X-ray 영상을 입력받아 폐렴 여부를 분류하는 딥러닝 모델을 구축하고, Grad-CAM++를 통해 모델이 영상의 어떤 영역을 근거로 판단했는지 시각화


프로젝트 동기

의료영상 AI에서는 단순히 높은 분류 성능을 얻는 것뿐만 아니라, 실제 질환을 얼마나 잘 탐지하는지와 모델이 적절한 영역을 보고 판단했는지를 함께 확인하는 과정이 중요

따라서 Scratch와 Transfer Learning의 성능을 비교하고, 다양한 평가 지표와 Grad-CAM++를 활용하여 모델의 성능과 판단 근거를 함께 분석

4. 데이터셋 재구성

  • 기존 Train / Val / Test를 통합한 후 Stratified Split
  • Train : Validation : Test = 6 : 2 : 2
  • 클래스 비율 유지 — NORMAL 약 27%, PNEUMONIA 약 73%
  • Train 3,514 / Validation 1,171 / Test 1,171

5. 전처리 계획

  • Input Resize: 224×224 - ResNet의 일반적인 ImageNet 입력 크기를 기준으로 설정
  • Normalization - ImageNet pretrained ResNet에 맞는 정규화 적용
  • Augmentation (데이터 증강) - 기존 데이터를 변형하여 데이터의 양과 다양성을 증가
  • 어떤 Augmentation을 사용할지는 추가 실험 예정

6. 모델 선정

전이학습 성능 향상 확인 실험

  • ResNet-50
  • Residual Connection을 통해 비교적 깊은 네트워크를 안정적으로 학습 가능
  • 이미지 분류에서 널리 사용되는 대표적인 CNN Backbone
  • ImageNet Pretrained Weight를 사용할 수 있어 전이학습 비교 실험에 적합

6-1. Scratch와 Transfer Learning 비교

A. ResNet from Scratch

ResNet-50 구조 + 랜덤하게 설정된 초기 가중치
→ Chest X-ray 데이터만으로 처음부터 학습

B. ResNet Transfer Learning

ImageNet 데이터로 미리 학습된 ResNet-50의 가중치 사용
→ Chest X-ray 데이터에 맞게 추가 학습(Fine-tuning)
→ 폐렴 분류 모델

같은 ResNet-50 구조를 사용하되, 처음부터 학습하는 방법과 이미 학습된 가중치를 활용하는 방법을 비교하여 전이학습이 폐렴 분류 성능 향상에 도움이 되는지 확인

7. Transfer Learning 학습 계획

  • 1. Backbone Freeze
    ImageNet에서 학습된 Backbone의 가중치는 고정하고, 새로 추가한 폐렴 분류 Classifier를 먼저 학습
  • 2. Fine-tuning
    이후 Backbone의 일부 또는 전체 Layer도 학습 가능하도록 변경하여 Chest X-ray 데이터에 맞게 추가 학습
  • 3. 클래스 불균형 대응
    우선 원본 클래스 비율을 유지하여 학습하고, 클래스별 성능을 확인한 뒤 필요할 경우 Class Weight 적용

8. 평가 방법

Accuracy 전체 예측 중 모델이 올바르게 예측한 비율
Recall (Sensitivity) 실제 폐렴 환자 중 폐렴이라고 올바르게 찾아낸 비율
Precision 폐렴이라고 예측한 환자 중 실제 폐렴인 비율
F1-score Precision과 Recall을 함께 고려한 지표
AUROC 여러 분류 기준에서 두 클래스를 얼마나 잘 구분하는지 평가
Confusion Matrix 정상과 폐렴을 각각 어떻게 맞추고 틀렸는지 확인

8-1. Accuracy만으로 평가할 수 없는 이유

예시 — 환자 100명 중 정상 90명 / 폐렴 10명

모델이 100명 모두를 정상이라고 예측한다면?

Accuracy 90% 90 / 100명 정답
Pneumonia Recall 0% 폐렴 환자 10명 모두 놓침

높은 Accuracy가 반드시 좋은 의료 AI 모델을 의미하지 않음. 따라서 Recall, Precision, F1-score, AUROC 등 여러 지표를 함께 평가

9. 모델 판단 근거 확인 (XAI)

  • 높은 분류 성능만으로는 모델이 올바른 영역을 보고 판단했는지 확인하기 어려움
  • 특히 의료영상에서는 병변이 아닌 문자, 촬영 위치, 영상의 특정 패턴 등을 근거로 판단할 가능성도 존재
  • 따라서 모델의 예측 결과뿐 아니라 어떤 영역을 근거로 판단했는지 확인할 필요가 있음
