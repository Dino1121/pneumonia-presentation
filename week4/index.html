GRAD-CAM++

Grad-CAM++란?

핵심 아이디어

마지막 convolution feature map을 이용해 예측 class에 기여한 위치를 heatmap으로 시각화

Grad-CAM과의 차이

일반 Grad-CAM보다 feature map 내부 위치별 중요도를 더 세밀하게 반영

성능만으로 보이지 않는 모델의 spatial attribution pattern을 비교하기 위한 도구로 사용

SCRATCH
  • 영상 상단 및 하단 경계
  • 검은 padding 인접 영역
  • 폐야 외부
  • 넓고 diffuse한 activation
TRANSFER LEARNING
  • 폐야 내부의 제한된 영역
  • 흉곽 내부
  • Scratch보다 더 국소적인 activation
  • 상대적으로 집중된 spatial pattern

RESULT 03 INSIGHT

Result 3 해석

의미

정답 여부가 달라지는 사례에서도 각 모델이 반응하는 위치가 어떻게 달라지는지 비교 가능

활용

오분류 사례를 함께 보면 모델의 실패 양상과 shortcut-like feature 가능성을 더 구체적으로 관찰 가능

정답 여부와 heatmap pattern을 함께 보면 단순 accuracy 비교보다 더 많은 정보를 얻을 수 있음
05

해석 및 한계

Shortcut-like Feature · Careful Interpretation

INTERPRETATION

Shortcut-like Feature 가능성

관찰
  • Scratch에서 영상 경계, padding 인접 영역, 폐야 외부 반응이 반복적으로 관찰
  • Transfer Learning은 상대적으로 폐야 내부에 더 집중된 경향
가능한 비병변적 cue
  • Image borders
  • Padding geometry
  • Crop / positioning 차이
  • Markers / text / artifacts
Scratch 모델의 반응은 dataset-specific shortcut-like feature 의존 가능성을 시사하지만, 현재는 정성적 관찰 수준
CAREFUL INTERPRETATION

Grad-CAM++ 결과로 말할 수 있는 것 / 없는 것

말할 수 있는 것
  • 두 모델의 spatial attribution pattern이 다름
  • Scratch에서 폐야 외부 반응이 관찰됨
  • Transfer Learning에서 더 국소적인 activation이 자주 나타남
말할 수 없는 것
  • 실제 병변을 정확히 localization했다고 단정
  • Transfer Learning이 임상적으로 더 옳다고 단정
  • Scratch의 shortcut learning을 확정
  • 붉은 영역이 confidence 또는 severity를 의미한다고 해석

각 CAM은 독립적으로 normalization되므로 색 강도의 절대값을 직접 비교하지 않음
